## 🧑‍💻 快速开始

1. 访问官网：**[https://orange.gomioo.com](https://orange.gomioo.com)**
2. 将你的运单号（支持换行、逗号、空格分隔）粘贴到输入框
3. 选择对应的承运商（支持混合查询）
4. 点击「开始查询」，等待进度条跑完
5. 点击「导出 Excel」下载完整结果

*是的，就是这么简单。*

## 🙋 常见问题

<details>
<summary>❓ 真的完全免费吗？</summary>
是的，目前以及可预见的未来都将保持免费。我们通过其他增值服务盈利，核心批量查询功能不会收费。
</details>

<details>
<summary>❓ 每天能查多少单？</summary>
没有硬性上限。只要你的单号有效，一次提交几千单完全没问题。我们仅出于公平使用原则，对极端的恶意请求做限流。
</details>

<details>
<summary>❓ 数据安全吗？我查询的运单号会被记录吗？</summary>
我们**不存储**任何用户提交的运单号及查询结果，所有操作仅在您的浏览器内完成，查询完毕后即清空缓存。
</details>

<details>
<summary>❓ 支持哪些语言？</summary>
目前为简体中文，后续会加入英语等多语言支持。
</details>
